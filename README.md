# Sound & Vision — управление студией звукозаписи

Локальное настольное приложение для управления студией звукозаписи. Интерфейс реализован на стандартных `tkinter` и `ttk`, данные хранятся в SQLite. Для работы приложения не нужны сторонние runtime-зависимости.

## Требования

- Python 3.12 или новее с установленным Tkinter
- [uv](https://docs.astral.sh/uv/) — для установки инструментов разработки и запуска тестов

## Запуск

Из корневого каталога проекта:

```bash
uv sync
uv run python -m studio_app.app
```

При первом запуске создаётся локальная база с демонстрационными записями и открывается регистрация. Пароль должен содержать не менее 8 символов; в базе хранится его PBKDF2-хеш. При следующих запусках приложение предложит войти.

База размещается в пользовательском каталоге данных операционной системы. Для сохранения базы версии Tkinter, созданной ранее из каталога `lab4`, используется каталог `SoundVisionTkinter`.

## Возможности

- управление клиентами, сотрудниками, помещениями, оборудованием, проектами и сеансами;
- добавление, редактирование и удаление записей;
- проверка пересечений сеансов по помещению и звукорежиссёру;
- изменение статуса сеанса с проверкой допустимых переходов;
- расчёт стоимости сеанса по ставке помещения и длительности;
- регистрация и вход локального пользователя;
- меню «О программе» и «Выход», отдельное окно с Canvas-логотипом.

## Проверки

```bash
uv run pytest
uv run ruff check .
```

Структура приложения:

- `studio_app/models.py` — объектная модель;
- `studio_app/database.py` — схема и подключение SQLite;
- `studio_app/service.py` — операции с данными и правила расписания;
- `studio_app/auth.py` — регистрация и проверка пароля;
- `studio_app/ui.py` — интерфейс Tkinter;
- `studio_app/app.py` — точка входа;
- `tests/` — автоматические тесты.
